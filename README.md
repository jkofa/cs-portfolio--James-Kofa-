 CS 330 Computational Graphics and Visualization Reflection

 How I Approach Designing Software
In this course, I learned how to plan a project before coding by thinking about object placement, textures, lighting, and user interaction. I used a step-by-step design process by first creating simple shapes, then improving the scene over time. This approach can help me in future projects because planning first saves time and reduces mistakes.

### How I Approach Developing Programs
While building my 3D scene, I used testing and small improvements each week to make progress. I learned how important it is to debug often and make changes one step at a time. My coding approach improved by becoming more organized, patient, and focused on solving problems.
